# میراث ایرانیان | نمونه نمایشی موبایل

اپلیکیشن آزمایشی فارسی و راست‌چین با **Expo SDK 54 / React Native** برای ارائه به مدیر مجموعه. این پروژه **هیچ ارتباطی با سرور، کاربران یا درگاه پرداخت واقعی ندارد**؛ محصولات، قیمت‌ها، درآمدها و وضعیت میزها ساختگی و صرفاً برای نمایش هستند.

## پیش‌نیاز
- Node.js LTS
- Expo Go روی گوشی Android یا iPhone
- رایانه و گوشی روی یک شبکه (یا استفاده از `npx expo start --tunnel` در صورت دسترسی)

## اجرا
```bash
npm install
npx expo start
```
سپس QR را با Expo Go اسکن کنید. برای اجرا در شبیه‌ساز: `npm run android` یا `npm run ios` (دومی نیازمند macOS و Xcode است).

## صفحات و تعامل‌ها
- خانه: بنر، خدمات و محصولات منتخب
- فروشگاه: جست‌وجو، فیلتر دسته‌بندی، افزودن به سبد
- سبد خرید: حذف محصول، جمع قیمت و شبیه‌سازی پیام پرداخت
- میزهای کار: هفت میز نمایشی و انتخاب میز
- شبکه: ساختار شماتیک و اشتراک کد دعوت ساختگی
- حساب: کیف پول آزمایشی، منو و لینک وب‌سایت اصلی

## نکات ضروری برای نسخه عملیاتی
1. دریافت API مستند، محیط staging و حساب تست از شرکت؛ بررسی منطق واقعی میزها و طرح پاداش.
2. احراز هویت و مجوزدهی در سرور، کنترل مالکیت جایگاه‌ها و ثبت رویدادهای مالی قابل ممیزی.
3. پرداخت از طریق سفارش سمت سرور و callback/webhook معتبر؛ تأیید نهایی فقط در backend، با idempotency.
4. طراحی سرویس‌های فروش، بازاریابی و کیف پول؛ کش، صف و پایش، سپس آزمون بار با سناریوی کاربران هم‌زمان. «یک میلیون بازدیدکننده» به‌تنهایی ظرفیت هم‌زمان را مشخص نمی‌کند.
5. ساخت خروجی با EAS Build، تست روی دستگاه و انتشار با حساب توسعه‌دهنده Android و Apple؛ بررسی قوانین انتشار اپ‌ها و مقررات مرتبط با طرح بازاریابی.

## ساختار
`App.js` نمونه تک‌فایلی برای سهولت مشاهده و ویرایش است؛ پیش از توسعه تجاری، آن را به ماژول‌های screens/components/services تفکیک کنید.

## وضعیت تست
فایل‌های پروژه آماده‌اند، اما نصب وابستگی‌ها و اجرای واقعی روی دستگاه در این محیط انجام نشده است. در نتیجه سازگاری نهایی باید پس از `npm install` روی گوشی بررسی شود.
